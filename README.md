| Service | Description |
|---------|-------------|
| [cli](https://github.com/omnidotdev/cli) | Core CLI |
| [cli-site](https://github.com/omnidotdev/cli-site) | Website |

## Getting Started

1. Copy configuration template:

   ```sh
   cp services.yaml.template services.yaml
   ```

2. Start development:

   ```sh
   tilt up
   ```
